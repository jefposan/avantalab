# Imagens diversas

Acervo pessoal de imagens sem uso direto no sistema AvantaLab.

Os arquivos desta pasta não participam da interface, da compilação, dos PWAs
ou dos aplicativos nativos. Eles são mantidos apenas como referência e não
devem ser considerados resíduos em auditorias futuras.

Antes de reutilizar uma imagem no produto, mova uma cópia para a pasta oficial
do módulo correspondente e registre a referência no código.
